# The Lazy App 🦥

> *"Why do today what you can avoid entirely?"*

A minimal, tongue-in-cheek web application designed for elite procrastinators, professional couch potatoes, and anyone currently running in low-power mode.

---

## ✨ Features

- **Instant Excuse Generator:** Generates bulletproof, scientifically questionable excuses to get you out of meetings, calls, and general commitments.
- **The "To-Don't" List:** A productivity list that refuses to be productive. Every task you add is automatically rescheduled for *Tomorrow™*, *Next Tuesday*, or *Pending cosmic inspiration*.
- **"Do Absolutely Nothing" Challenge:** An anti-productivity tracker. The timer only ticks if you stay completely still. Move your mouse, scroll, or touch a key, and the app resets and scolds you for exerting effort.
- **Zero Dependencies:** Pure vanilla HTML, CSS, and JavaScript. No build steps, no `npm install`, no setup fatigue.

## 💻 Getting Started

Because this is a lazy app, the setup requires almost zero effort:

### Method 1: Just Open It
1. Clone or download this repo:
   ```bash
   git clone https://github.com/shellytom81-cyber/lazy-app.git
   ```
2. Double-click `index.html` to open it in your favorite browser.
3. Relax.
